# uvc-util (bundled)

macOS UVC camera control via IOKit — same approach as [ofxUVC](https://github.com/kylemcdonald/ofxUVC).

Sources are downloaded automatically on first use from
https://github.com/jtfrey/uvc-util (MIT) and compiled to `~/.cache/marimapper/uvc-util`.

Manual build:

```bash
./scripts/build_uvc_util.sh
```
